# Superpowers working docs

Design specs, implementation plans, and decision records for STARN work.

## Layout

| Path | Holds |
|---|---|
| `specs/` | Live design specs for work in flight |
| `plans/` | Live implementation plans for work in flight |
| `designs/` | Live design documents and mockup briefs for work in flight |
| `archive/` | Completed work, kept for history. Nothing here is active. |

Rules:

- One spec + one plan per sub-project. Write the plan before code, put it here.
- When a sub-project ships, move its spec/plan/design into `archive/` in the
  same commit that closes the task. `archive/` is a record, not a backlog.
- Never renumber or rewrite archived docs; supersede them with a new file.
